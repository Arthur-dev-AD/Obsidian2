# I ) Notions de température

## 1 ) Définition

La température mesure en fait l'agitation moléculaire appelée agitation thermique. Lorsqu'on chauffe un corps, on augmente la vibration moyenne des particules qui le constitue et donc l'agitation thermique : sa température augmente.

## 2 ) Les thermomètres

Il existe différents types de thermomètres :

- ==🔴Thermomètres à dilatation de liquide==
	- Exemple : le thermomètre à alcool
- ==🔴Thermomètre électriques==
	- Exemple : Thermistance, thermocouple
- ==🔴Thermomètres infrarouges==

> [!note] REMARQUE 
> Il existe d'autres types de thermomètres beaucoup moins utilisés (Thermomètre magnétiques et autres).

## 3 ) Les échelles de température
